# Trishul 🛡️

An end-to-end military-grade digital workshop & fleet maintenance management platform featuring asset tracking, live departmental scheduling calendars, procurement vendor evaluations, inventory alerts, individual personnel profiles, and AI-powered insights.

You can view the live deployment here: [Live Website](https://trishul-eight.vercel.app)

---

## 🚀 Built With

* **JavaScript** (98.6%) - Core application logic, backend services, and frontend functionality.
* **HTML** (1.2%) - Markup and structure.
* **Other** (0.2%) - Configuration, workflow, and build scripts.
